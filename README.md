# claude-for-faculty-20260608

Workshop materials for **Day 1** of the third week of the *Summer of
Claude* faculty series at the Bok Center / Learning Lab, Harvard.

Session: 2026-06-08, 1:00–2:30pm, Learning Lab Studio, 50 Church St.

This is a Cowork-focused day: faculty work in the desktop app on a
local folder of demo materials (recipe photos, population data,
literature samples, glossary references) and finish by drafting a paper
"recipe card" for one real task of their own. The plan of show is in
[`day-1-plan-of-show.md`](day-1-plan-of-show.md).

## What's in this folder

- `day-1-plan-of-show.md` — the timed plan for the session.
- `recipe-photos/` — handwritten recipe-card images used for the
  rename → transcribe → publish demo.
- `recipe-website/` — sample output of the demo (HTML + assets), for
  reference.
- `population-data/` — CSVs used for the population-pyramid artifact
  demo.
- `context-research/` — papers on primacy, context rot, and lost-in-
  the-middle behavior.
- `literature/` — Shakespeare and other text-corpus samples.
- `glossary-references-cheat-sheets/` — AI glossary and the
  text-file-types cheat sheet handout.
- `handouts/` — the printable handouts for the session.
- `bok-people/` — bios / photos of the workshop team.
- `science-and-cooking/` — Becca's worked-example materials.
- `Claude Cowork Session Notes for June 1.docx` — notes from the
  previous run (Week 2, 2026-06-01), kept for reference.
